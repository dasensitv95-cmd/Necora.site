# Nexora Soluções — site demonstrativo

Site empresarial responsivo com quatro páginas: Início, Sobre, Serviços e Contato.

## Como visualizar
Abra o arquivo `index.html` no navegador.

## Como publicar gratuitamente pelo GitHub Pages
1. Crie um repositório no GitHub, por exemplo `nexora-site`.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde alguns minutos. O GitHub mostrará o endereço público do site na mesma tela.

## Personalização
- Troque nome, textos, e-mail e telefone fictícios nos arquivos HTML.
- Ajuste cores e fontes em `css/style.css`.
- O formulário de contato usa `mailto:` e abre o aplicativo de e-mail do visitante. Para receber mensagens diretamente no site, será necessário integrar um serviço de formulário ou backend.

**Atenção:** Nexora Soluções, contatos, indicadores e informações são fictícios e servem apenas como demonstração.
